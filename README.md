A word lookup app built with Flutter. Type in a word and get its full set of verb forms and conjugations back, powered by a REST API with local offline caching.

---

## 📱 Features

| Area | Description |
|---|---|
| **Word Lookup** | Search a word and get its verb forms and conjugations |
| **Offline Cache** | Previously looked-up words are cached locally with Hive |
| **Connectivity Awareness** | Detects network status and falls back to cached data offline |

## 🛠️ Tech Stack

| Category | Technology |
|---|---|
| Framework | Flutter |
| Networking | `http` |
| Local Storage / Cache | `hive`, `hive_flutter`, `path_provider` |
| Connectivity | `connectivity_plus` |
| UI | `cupertino_icons` |
